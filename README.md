# Restaurant Booking DF2

Веб-приложение для бронирования столиков в ресторане, разработанное на Django.

Проект представляет собой Fullstack-приложение с пользовательской частью сайта и административной панелью Django Admin. Пользователь может ознакомиться с рестораном, посмотреть меню, зарегистрироваться, авторизоваться и забронировать столик. В личном кабинете доступны просмотр, редактирование и отмена собственных бронирований.

## Возможности проекта

### Для посетителей

1. Главная страница: 
    * Описание ресторана.
    * Перечень предоставляемых услуг.
    * Контактная информация.
    * Форма для обратной связи.
2. Страница "О ресторане": 
    * История ресторана.
    * Миссия и ценности.
    * Команда.
    * Меню (сделала_дополнительно)
*
*3. Страница бронирования: 
    * Форма для бронирования столика.
    * Просмотр доступности столиков.
    * Подтверждение бронирования.

### Для зарегистрированных пользователей

* регистрация;
* авторизация;
* выход из аккаунта;
* личный кабинет;
* просмотр истории бронирований;
* просмотр текущих бронирований;
* редактирование собственных бронирований;
* отмена собственных бронирований.

Пользователь имеет доступ только к своим бронированиям.

### Для администратора

Через стандартную административную панель Django доступны:

* управление пользователями;
* управление бронированиями;
* управление контентом сайта;
* управление изображениями ресторана;
* добавление и редактирование информации о ресторане;
* управление изображениями меню.

## Архитектура

Проект построен на архитектуре **MVT (Model – View – Template)**, используемой Django.

### Основные компоненты

**Model** — описывает структуру данных и взаимодействует с PostgreSQL через Django ORM.

**View** — содержит бизнес-логику обработки запросов.

**Template** — отвечает за отображение страниц пользователю.

В проекте используются как **FBV (Function-Based Views)**, так и **CBV (Class-Based Views)**.

## Установка и запуск локально

### 1. Клонирование проекта

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd restaurant_booking_df2_diplom
```

### 2. Установка зависимостей

Проект использует Poetry.

Установить зависимости:

```bash
poetry install
```

### 3. Создание файла `.env`

В корне проекта необходимо создать файл `.env` на основе `.env.template`.

Пример:

```env
SECRET_KEY=your-secret-key
DEBUG=True

POSTGRES_DB=restaurant_booking
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your-password
POSTGRES_HOST=localhost
POSTGRES_PORT=5433
```

Файл `.env` не должен добавляться в Git.

### 4. Запуск PostgreSQL

PostgreSQL можно запустить через Docker Compose:

```bash
docker compose up -d db
```

При локальном запуске Django используется:

```text
localhost:5433
```

Порт `5433` на компьютере соответствует стандартному порту PostgreSQL `5432` внутри Docker-контейнера.

### 5. Применение миграций

```bash
poetry run python manage.py migrate
```

### 6. Создание администратора

```bash
poetry run python manage.py createsuperuser
```

Следовать инструкциям в терминале.

### 7. Запуск Django

```bash
poetry run python manage.py runserver
```

После запуска сайт доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Запуск через Docker Compose

Проект содержит `Dockerfile` и `docker-compose.yml`.

Docker Compose запускает два основных сервиса:

* `web` — Django-приложение;
* `db` — PostgreSQL.

### Запуск проекта

```bash
docker compose up --build
```

После успешного запуска сайт доступен по адресу:

```text
http://localhost:8000/
```

### Запуск в фоновом режиме

```bash
docker compose up -d --build
```

### Проверка запущенных контейнеров

```bash
docker compose ps
```

### Остановка контейнеров

```bash
docker compose down
```

Данные PostgreSQL сохраняются в Docker volume `postgres_data`.
