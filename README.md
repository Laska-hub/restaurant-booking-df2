# Restaurant Booking

Веб-приложение для бронирования столиков в ресторане.

## О проекте

Приложение позволяет пользователям просматривать доступные столики ресторана и бронировать их на выбранную дату и время.

Пользователь может:

* зарегистрироваться и авторизоваться;
* просматривать доступные столики;
* создать бронирование;
* редактировать бронирование;
* отменить бронирование;
* просматривать свои бронирования в личном кабинете.

Администратор может управлять пользователями, столиками и бронированиями через административную панель Django.

При создании или изменении бронирования система автоматически подбирает подходящий свободный столик с достаточным количеством мест.

## Основные возможности

### Регистрация и авторизация

* регистрация нового пользователя;
* вход и выход из аккаунта;
* разграничение доступа для авторизованных и неавторизованных пользователей.

### Бронирование столика

Пользователь указывает:

* дату;
* время;
* количество гостей.

Система автоматически проверяет наличие свободного столика подходящего размера и назначает его бронированию.

При редактировании существующего бронирования текущий столик также учитывается как доступный, чтобы бронирование не блокировало само себя.

### Управление бронированиями

Авторизованный пользователь может:

* просматривать свои бронирования;
* редактировать бронирование;
* отменять бронирование.

При редактировании повторно выполняется проверка доступности столика.

### Административная панель

Администратор может управлять:

* пользователями;
* столиками;
* бронированиями.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:Laska-hub/restaurant-booking-df2.git
cd restaurant_booking_df2_diplom
```

### 2. Установка Poetry

Проект использует Poetry для управления зависимостями.

Проверить установленную версию:

```bash
poetry --version
```

### 3. Установка зависимостей

```bash
poetry install --no-root
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.template`.

Пример:

```env
SECRET_KEY=your-secret-key
DEBUG=True

DB_NAME=restaurant_booking
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5433
```

Значения переменных необходимо заменить на собственные.

### 5. Выполнение миграций

```bash
poetry run python manage.py migrate
```

### 6. Запуск сервера

```bash
poetry run python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

## Запуск с Docker

Для запуска проекта с использованием Docker Compose выполните:

```bash
docker compose up -d
```

Проверить состояние контейнеров:

```bash
docker compose ps
```

Остановить контейнеры:

```bash
docker compose down
```

После запуска приложение доступно на порту, указанном в `docker-compose.yml`.

В текущей конфигурации:

```text
http://127.0.0.1:8001/
```

PostgreSQL работает внутри Docker-контейнера.

## Логика выбора столика

Для исключения дублирования логики поиска свободного столика она вынесена в отдельный сервис:

```text
restaurant/services.py
```

Сервис получает дату, время и количество гостей, после чего:

1. выбирает активные столики с достаточным количеством мест;
2. исключает столики, занятые на выбранные дату и время;
3. при редактировании учитывает текущий столик бронирования;
4. выбирает самый маленький подходящий свободный столик.

Это позволяет использовать одну и ту же бизнес-логику при создании и редактировании бронирования.
